## 📝 [刷题总结](./刷题总结.md)

### 算法选择要点

| 数据结构/算法 | 适用场景 |
|-------------|---------|
| **单调栈** | 查找每个元素左右第一个比它大/小的元素 |
| **单调队列** | 滑动窗口内最大值/最小值问题 |
| **二叉堆** | 动态查找最大值/最小值 |
| **Dijkstra** | 单源最短路径，无负权边场景 |

### 最短路径算法说明

Dijkstra 算法流程：
1. 选取离源点最近的未访问节点
2. 更新该节点所有邻接点到源点的距离
3. 标记当前节点为已访问
4. 重复执行直至所有节点都被访问

路由器场景也使用 Dijkstra 算法：
- 通过链路状态路由协议（如 OSPF）获取网络拓扑
- 每个路由器广播链路状态包（LSP）
- 构建链路状态数据库（LSDB）
- 独立运行 Dijkstra 计算最短路径树
